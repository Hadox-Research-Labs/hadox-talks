Los ejemplos no representan resultados del grupo. Incorporar entregas reales revisadas y ensayar las funciones en una cuenta compatible antes de la demostración.

El contenido conserva C de 20 puntos y memo individual de hasta dos páginas de 40 puntos. Las fechas y el canal de entrega corresponden al aula institucional.
